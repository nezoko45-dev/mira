LUNA GOTHIC COMPANION — PORTABLE CHROME BUILD

1. Keep every file/folder in this ZIP together.
2. Run start.bat.
3. The local Luna backend starts first.
4. Chrome opens Luna at http://127.0.0.1:8765/.
5. Enter your Deepgram and Anthropic API keys in Luna and save them locally.
6. Start a voice call. Deepgram transcribes your microphone and Claude generates Luna's replies.
7. OpenVoice V2 provides local voice output when a voice_reference.wav is installed.

VOICE REFERENCE
Put a short, clean voice sample at:
%APPDATA%\LunaGothicCompanion\voice_reference.wav

The desktop build is independent of Vercel. Chrome is the UI and Luna-Backend.exe is the local backend.
